Changelog & Updates

28.11.2026 — - Hotfix

Fixes & Improvements

  • Fixed materials from the models/ directory appearing in ordinary texture browsing.
  • Fixed material directory exclusions not working properly.
  • Fixed several issues with saving and copying material exclusion settings.
  • Fixed Only Used Textures not displaying any textures.
  • Fixed a crash caused by creating spheres with too many subdivisions.
  • Fixed incorrect selection coordinates in free-camera mode.
  • Fixed automatic selection cycling while using free-camera mode.
  • Fixed several potential material enumeration issues.
  • Increased the editor's brush face limit from 256 to 1024.
  • Reworked internal brush storage to allocate memory dynamically.
  • Restored support for creating spheres with up to 32 subdivisions.
  • Improved vertex manipulation support for complex brushes.
  • Fixed several potential geometry buffer overflows.
  • Improved brush clipping and decal rendering stability.
  • Added a warning when compiling brushes that may exceed the compiler's supported face limit.
  • Replaced the old material exclusion folder browser with a modern Windows folder picker.
  • Excluded materials are no longer loaded unnecessarily in the background.

Special thanks to Le Glaconus for reporting these issues.

27.11.2026 — - Texture Browser Hotfix

Fixes

  • Fixed the Texture Browser becoming empty after reopening it.
  • Fixed Texture Browser initialization and cleanup issues.
  • Fixed stale texture selection and layout states.
  • Fixed an issue with the Only Used Textures filter when no map is open.
  • Fixed a potential buffer overflow when selecting texture groups.
  • Improved error handling.
27.11.2026 — - Major Update

Fixes

  • Editing or painting displacements no longer crashes the editor.
  • VMF files can now be saved in any directory; the editor no longer requires them to be saved in the game's map directory.
  • Fixed a rare crash in the Texture Browser.
  • Experimental attempt to address lag on AMD GPUs.
  • Code optimizations.
  • Fixed VisGroups (holy shit, finally).
  • VMF saving no longer reports success after a failed save and now creates a backup of the VMF.
  • Fixed compiler process and pipe handle leaks.
  • Failed or cancelled compilations now retain their temporary files for troubleshooting.

Features

  • Added the ability to change the FPS cap (including uncapped FPS) and FOV in the 3D view.
  • Added an option to disable Discord RPC.
  • Updated the editor startup splash screen.
  • The editor now creates a copy of the VMF during map compilation in case of a crash or corruption.
  • 3D skyboxes are now rendered in the map.
  • Worldcraft++ now remembers its window size after closing.
  • Added private map snapshots to prevent ongoing edits from interfering with compilation.
  • Added a Cancel Compile button.
  • Improved compiler output handling and error reporting.
  • Added background map compilation.
  • Reworked the compile process window into an independent window.
  • 3D viewport rendering is no longer disabled during compilation.

2D View

  • Backported some features from the 2007 Source code.
  • Removed synchronous repainting during panning.
  • Fixed incorrect scrollbar boundaries.
  • Reused the existing GDI device context instead of creating an additional one during rendering.
  • Removed unnecessary copying of old window pixels during panning.

3D View

  • Fixed geometry-based model picking.
  • Fixed issues with hit ordering and buffer handling.
  • Ropes now use textures instead of thin RGB lines.
  • Skybox preview can now be enabled through the Camera button.

Model Browser - Major Improvement

  • Preview models now use independent model instances instead of cached models shared with map entities.
  • The preview camera now persists throughout the dialog's lifetime.
  • Double-clicking empty list space no longer confirms the selection.
  • Model information no longer incorrectly implies that every model supports prop_static/$staticprop.
  • Added a minimum dialog resize limit.
  • Directory junctions are skipped to prevent scanning loops.
  • Redesigned the Model Browser.
  • Added a session-level index cache.
  • Fixed the camera.

Displacements

  • Improved displacement editing accuracy and stability: the brush now follows the actual terrain surface instead of jumping between vertices.
  • Updated AutoSew.
  • Optimized geometry recalculation so that surfaces with newly queued vertex changes are rebuilt.
  • Improved the Undo manager.

Texture Browser

  • Fixed potential crashes caused by long search queries and material names.
  • Fixed crashes when no textures matched the search filter.
  • Fixed double-clicking empty space in the Texture Browser.
  • Fixed incorrect texture selection after changing search filters.
  • Fixed the Show Errors checkbox not working properly.
  • Fixed several scrollbar and texture highlighting issues.
  • Fixed crashes caused by invalid material previews.
  • Improved search filter handling.
  • Added a message when no textures match the search.
  • The Texture Browser now remembers the last used keyword filter during the session.
  • Fixed an issue with restoring invalid Texture Browser window positions.
  • Fixed an issue with legacy WAL texture names.
  • Fixed a crash when browsing used textures without an active map.
  • Optimized Texture Browser performance.
  • Added caching for texture search results.
  • Added incremental loading of texture previews.
  • Improved scrolling and mouse wheel handling.
  • Optimized texture selection and thumbnail positioning.
  • Improved performance when resizing the Texture Browser.
  • Improved keyword and material-type filtering.
  • Fixed unloaded materials appearing under incorrect material-type filters.
  • Fixed failed material previews being repeatedly loaded.
  • Reduced unnecessary texture enumeration and interface redraws.

Expert Mode

  • Reworked the Expert Mode compilation interface.
  • Added 10 predefined compilation configurations.
  • Added support for creating custom HDR compilation configurations.
  • Added an option to restore missing default configurations.
  • Added command duplication.
  • Added configurable compiler process priority.
  • Added automatic BSP publishing.
  • Added required-file and compiler executable validation.
  • Expert Mode now remembers the last selected configuration and compiler priority per game configuration.
  • Improved compatibility with background compilation.
  • Fixed several configuration management and command ordering issues.
  • Fixed potential crashes caused by malformed configuration files.
  • Improved configuration saving reliability.

Update - 19/2/26
  • Added faster loading and made sure that the leaked Hammer will keep the previously opened .vmf file in memory.
  • Fixed Lazy Evaluation in Texture Browser, which caused a loop due to textures not being loaded into memory, causing Leaked Hammer to become unresponsive.
  • Improved Mouse Wheel Speed, allowing the user to move around the uncompiled map faster than having to hold W key. The user can also manipulate the speed of the camera by holding Shift and using the scroll.
  • Added new Hotkeys:
    • H - Quick Hide Selection
    • U - Unhide all
    • ESC - Quick Deselect
  • Improved auto-visgroup.
  • Added a 2003-looking Hammer model browser.
  • Improved Grid Navigation inspired by J.A.C.K and Hammer++. (Suggestion made by soup2.0)
  • Added a secret easter egg.
  • Fixed a bug with Texture Scale Reset.
  • Fixed Grid Drift, where if the user would place an entity (e.g., at 2048.55) and saved, Hammer would write it as 2048.6 and make the entity off-grid. (Which was a risk of creating leaks)
  • Re-fixed an error about uncapped FPS; the previous fix used Sleep(30), which was at first helpful. DWM saw those as requests and slowed Hammer back to 30 fps.
  • Fixed the infamous Vertex Snap / Invalid Solid bug.
Update - 8/2/26
  • Re-added .map and .RMF support.
  • Rewrote CWorldcraft::Run to remove the hard-coded 60 FPS sleep limit, the main loop now prioritizes message processing and rendering immediately when the application is active, providing minimum input latency and maximum smoothness.
  • Implemented a thread sleep (10ms) trigger when the application is inactive or minimized to prevent unnecessary CPU consumption while multitasking.
  • Added timeBeginPeriod(1) to InitInstance, this forces the Windows timer resolution to 1ms, eliminating micro-stutters and jitter in the 3D viewport animations previously caused by low-precision system timing.
  • Removed hardcoded render distance caps in CMapView3D. View frustum Far Z is now initialized to 300,000 units.
  • Optimized hotkey logic for view distance control to support large-scale adjustments.
  • Fixed CMapStudioModel render distance not synchronizing with the active camera frustum settings.
  • Rewrote CMapView2D::DrawGrid to support adaptive spacing. Grid lines now double in interval (e.g., 64 -> 128) as zoom decreases, ensuring line spacing never falls below 4 pixels.
  • Fixed GDI rendering issue where the grid would fail to render (black screen) at low zoom factors due to sub-pixel grid spacing.
  • Fixed a bug where pasted brush-work wouldn't paste on the location chosen by the user and instead, appear far away from the chosen place.
  • Made sure that the camera movement in editor doesn't stutter when having high FPS or using scroll and W key for fast moving.
  • Added a function inspired by Hammer++ to hide Nodraw textures to make them stop rendering in Hammer Editor under the F5 key. (does not function, possibly requires a community fix in future.)
  • Increased Ray Length from 4096/8192 units to 10,000 units.
  • Forced map compiler to inject -red2black flag into VRAD parameters.
  • Added memory leak detection.
  • Fixed Squashed Textures in Hammer Editor's Texture Browser.
  • Upgraded 2D Orientation Arrows which is based on 2007 Hammer, it will allow mappers to see if info_player_start or prop_static are correctly placed by showing yellow line in Top (2D) View.
  • Added Auto-VisGroups and made sure that they automatically make categories.
